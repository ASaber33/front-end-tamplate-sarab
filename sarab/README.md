# Sarab Restaurant Website

A responsive restaurant landing page built with HTML, CSS, and Bootstrap 5.

## Features

- Menu, gallery, chef, reservation, and contact sections
- Responsive layout for mobile and desktop
- CSS-based countdown and interactive UI

## Run locally

Open `index.html` in a browser, or use a local development server such as VS Code Live Server.

Bootstrap and Google Fonts are loaded from CDNs, so an internet connection is required.
